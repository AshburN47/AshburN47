# Esther Ejiro

Frontend Engineer building accessible, type-safe interfaces and inclusive design systems with TypeScript, React, Next.js, and modern testing workflows.

I focus on component architecture, keyboard and screen-reader experiences, resilient application states, and the details that help digital products work for more people. My approach brings accessibility, maintainability, automated testing, and performance into the interface workflow from the start.

## What I Build

- Responsive web applications for desktop and mobile experiences.
- Accessible forms, navigation, dialogs, dashboards, and data-heavy interfaces.
- Reusable component systems with documented interaction patterns.
- Clear loading, empty, error, success, and recovery states.
- Automated accessibility and end-to-end checks in continuous integration.

- Semantic structure, accessible names, keyboard navigation, and focus management.

I am building a public accessible-component library with React, TypeScript, Storybook, Playwright, and axe. It demonstrates keyboard behavior, screen-reader semantics, form validation, reusable design tokens, automated accessibility checks, and documented usage decisions.
